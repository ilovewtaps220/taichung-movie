# taichung-movie

零費用的台中電影院時刻表網站，提供影城、電影、日期下拉選單搜尋。

## 已建立

- `src/`：網站畫面、樣式、搜尋功能
- `data/`：影城清單與時刻表快照
- `data/raw/`：官方網站抓取內容的原始保存
- `assets/`：預留圖片、圖示、字型
- `docs/`：預留規劃文件

## 本機預覽

在專案根目錄執行：

```bash
python -m http.server 8000
```

再開啟 `http://localhost:8000/src/`。直接雙擊 HTML 會被瀏覽器的安全規則阻擋 JSON 載入。

## 資料來源

資料來自使用者指定的六家影城官方公開頁面。影城名稱可能與官方目前顯示名稱不同，因此保留使用者指定名稱，並在備註標示官方現名。場次會變動，正式使用前應以官方頁面為準。

## 零費用部署

可使用 GitHub Pages 發布靜態網站，不需要購買主機或網域；也可以只在自己的電腦使用。本版本沒有付費 API、資料庫或後端服務。
